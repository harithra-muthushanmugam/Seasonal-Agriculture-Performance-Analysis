# Major Project: Seasonal Agriculture Performance Analysis

## Overview
This project analyzes agricultural performance metrics (Yield, Profit, Water Efficiency, Rainfall) across different seasons (Kharif, Rabi, Zaid) using a dataset of 4,000 farm records.

## Tech Stack
* Python 3.x
* Pandas, NumPy
* Matplotlib, Seaborn
* Jupyter Notebook / Google Colab

## Key Findings
* **Kharif Season:** Highest average yield (~5.63 Tonnes/Ha) and total profit (₹31.83 Cr).
* **Rabi Season:** Stable yield (~5.04 Tonnes/Ha) and moderate profit (₹14.27 Cr).
* **Zaid Season:** Lowest yield (~4.64 Tonnes/Ha) and net deficit (-₹1.47 Cr) due to high irrigation costs in dry conditions.

## Project Structure
* `seasonal_agriculture_performance_dataset.csv` - Raw agricultural dataset.
* `*.ipynb` - Python code notebook containing data cleaning, analysis, and visual charts.
* `*.pptx` - Project presentation slides.
